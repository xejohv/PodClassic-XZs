# 更新记录 / Changelog

## v1.5.87

- **音量回到进度条本体**：删掉独立的那根短音量条，转盘/物理音量键都改成同一条进度条临时画音量格数，两端时间位换成喇叭图标，2 秒后自动回落。条身位置与长度全程不动（实测两态均为 x=245→835），切换零跳动。两套播放页（默认主题 / 第三主题）同步生效。
- **修复物理音量键不联动**：`VolumeUtil.Watcher` 的回调此前只改了数值、没把音量"显示出来"，所以按音量键只有声音变、屏幕没反应；现在按键即进入音量显示并同步格数。
- **长菜单滚动条：首帧就在、宽度不跳、窄栏不裁字**：判定依据换成"完整放得下几行"（`floor`，扣内边距的可视高度 / 实测行高），条目多过它就是真的会滚。分页式列表里 adapter 只持一屏，`computeVerticalScrollRange()` 恒等于列表高度，判不出长列表——音效页 9 项、播放与显示页 8 项按渲染行数（`ceil`）算正好"放得下"，所以一根滚动条都没有，这次修掉。首帧先量行高再刷新列表；槽位只在整屏宽列表里预留（滚动全程文字宽度零位移），主页左栏这类窄栏不预留、恢复满宽，不再把「附加程序」「随机播放」裁掉（v1.5.87 首版曾出现，已回退）。
- **「重置」文案汉化**：简体中文下「Reset All Settings / Reset All / Cancel / Reset」改为「恢复所有设置 / 恢复全部设置 / 取消 / 恢复」，繁体同步为「回復所有設定 / 回復全部設定」。

## v1.5.86

- **设置页改成分类二级菜单**：原来 25 项挤在一页，滚到哪儿都分不清。现在首页只有 5 行——播放与显示 / 音效 / 录音 / 外观与操作 / 系统，点进去才是各项开关，返回路径与以前一致。
- **每项归位**：播放与显示（自动播放、播放顺序、随机播放、重复播放、睡眠定时、显示歌词、显示歌手和专辑、显示时间、CoverFlow）；音效（均衡器、系统AGC、TomSteady 及设置、胆机音效及设置、DC相位线性器及设置）；录音（录音质量）；外观与操作（夜间模式、机身配色、按键反馈）；系统（关于本机、语言、辅助功能、重置）。
- **音效组首行「音效说明」**：一页可滚动的文字，用人话解释系统AGC / TomSteady / 胆机音效 / DC相位线性器各自在干什么，不用去猜缩写。说明不塞进列表行里，避免长句把行高撑成五行、列表更乱。
- **删掉「与其他应用同时播放」**：这台机器就是一台纯 iPod Classic，不存在边听歌边看别的应用放片的场景，开关留着只会让人担心误操作；音频焦点仍默认申请，行为不变。
## v1.5.85

- **新增「录音」（语音备忘录）**：进「附加程序 → 录音」。首行「开始录音 / 停止录音」，录制中右侧实时走时；下面按时间倒序列出本机录音，点开直接用播放器播放，长按弹二次确认删除。录音统一存在内置存储 `Recordings/` 目录，插数据线（U 盘模式）就能拷出，也会被系统媒体库扫描到。
- **设置里新增「录音质量」**：高（44.1 kHz / 192 kbps）、标准（44.1 kHz / 128 kbps）、低（22 kHz / 64 kbps）三档循环。开始录音会自动暂停音乐，避免串音；录完自动刷新时长。
- **CoverFlow 是真实功能，不是空开关**：开关打开后，「音乐」菜单最底部会多出一行 CoverFlow（要往下滚一屏才看得到，这也是之前"看不出区别"的原因）。点进去是真正的封面流：左右转动浏览专辑，点中间封面进入该专辑曲目。
- **CoverFlow 重新排版**：按屏幕可用高度反推封面尺寸，封面 + 倒影 + 专辑名/歌手整块正好填满上半屏；解决了原来"上边一大片空白、倒影被下沿裁掉、文字压在倒影上"的问题；两侧只保留 2 层侧封面，不再是挤在右边缘的一堆碎片。
- **CoverFlow 触摸修复**：Compose 子视图会把 `DOWN` 事件吞掉，父层的左右滑动监听收不到，原来在封面区横向滑动完全切不动；改由 InterceptTouchEvent 统一接管，左滑/右滑翻专辑、点中间封面进专辑曲目都已真机实测。
- **录音播放标题精简**：录音标题栏原本是完整 `录音 11-22 15:37`，播放页标题区放不下会跑马灯滚动；播放时只显示 `录音 15:37`，列表里仍是完整日期时间。
- **「录音质量」右侧值改成短标签**：原来 `高（44.1 kHz）` 被列表列宽截断成 `高（44.1…`，现在只显示 高 / 标准 / 低，具体参数见本条上文。
- **修复「删掉正在播放的录音后返回主页闪退」**：封面/时长读取原来直接 `setDataSource(已删除的文件)`，抛 `IllegalArgumentException` 无人兜底；现在读取内嵌封面一律 try/catch 返回空图，删除时若正播该录音会先停播并从播放列表摘除。
- **修复「显示歌词」打开后播放页闪退**：v1.5.84 把歌词控件换成 AppCompatTextView，播放页仍按自定义 `widget.TextView` 强转，一播歌就 `ClassCastException`。现已改回自定义控件，并在代码里设单行 + 末尾省略号，长句不再溢出。

## v1.5.78

- **语言切换真正落盘**：`SPManager.save()` 由异步 `apply()` 改为同步 `commit()`——此前点完语言立刻杀进程，偏好还没写进磁盘，所以「设置语言无效」反复出现。
- **切语言不再退出应用**：改为原地 `recreate()` 重建界面，中文 ↔ 英文双向切换时整屏立刻跟着变，不会再闪一下系统桌面。
- **收藏 / 播放模式反馈改用顶部 Toast**：标题栏里那行提示文字在真机上被系统状态栏压住，永远看不见；改成系统 Toast（顶部居中），"已收藏 / 已取消收藏 / 单曲循环"都看得见。
- **音量条模式下隐藏两端时间**：音量条出现时 `00:00 / -03:08` 自动隐去，换回进度条再显示，与更新说明一致。

## v1.5.77

- **长按中央键只保留一种含义：收藏**。曲目列表、专辑/艺术家列表、文件浏览长按都是"收藏 / 取消收藏"，收藏过的条目名字前顶一个 ★，在收藏页里长按则直接取消并从列表移除；播放页长按中央键收藏正在播的这首，默认主题会气泡提示"已收藏 / 已取消收藏"。
- **取消一切"长按切播放模式"的手势**：v1.5.76 挂到播放键的那套、以及 3rd 主题直接切下一档的，全部撤掉；播放模式只从播放页右上角的图标点（点一下切随机/循环/单曲，旁边还有一个按钮切全部循环），当前值用气泡提示。
- 顺带删掉了只服务那套手势的「播放模式」菜单页，减少一处入口分裂。

## v1.5.76

- **播放模式入口挪到"长按播放键"**：转盘底部的播放/暂停区长按此前没有任何绑定（`onPauseLongClick` 回调一直是空的），放上去零冲突。长按 500ms 起弹出「播放模式」菜单（顺序/随机/单曲循环 + 全部循环，点一下切换）；长按期间回调每 600ms 重复一次，菜单已开着就不再叠页。
- **短按不受影响**：播放/暂停的短按只在手指 400ms 内抬起时触发，长按从 500ms 才开始，两者不会互相误触。
- **播放页中间键长按不再接管**：默认主题原来长按中央键开同一个菜单、3rd 主题是直接切下一档播放模式，现在统一收进"长按播放键"，中间键长按回到无动作。

## v1.5.75

- **容量把 SD 卡也算进来**：之前只 stat 了内置 `/data`，插卡后卡上的空间完全没算，歌放在卡上就会出现"歌一堆、容量却没变"的怪现象。现在总量 = 内置 + 外置卡，可用同理；插着卡时「关于本机」会多出四行明细（内部存储 / 内部可用 / SD卡 / SD卡可用），没插卡则跟以前一样只有两行。
- **歌曲收藏有入口了**：曲库自带「收藏的歌曲 / 收藏的专辑 / 收藏的艺术家 / 收藏的文件夹」，但把歌加进收藏此前只有"文件浏览长按音频文件"这一条小路，实际等于找不到。现在歌曲列表里长按中央键就是收藏 / 取消收藏，收藏过的曲目标题前会顶一个 ★；在「收藏的歌曲」页里长按取消，这一条会直接从列表里消失。

## v1.5.74

- **容量统计改精确值**：原来拿 `blockCount × blockSize ÷ 1024³` 直接取整，21.6 GB 会显示成 21、16.4 GB 显示成 16，看着就像算错；而且分子含文件系统保留块、分母只算可分配块，两者口径不一致，差额被误算成"已用"。现在统一用 `StatFs` 的字节接口（总容量 = 全部块，可用 = 可分配块），保留一位小数，整数值自动省掉 `.0`，跟 iPod classic 的写法一致。
- **音乐数量与实际曲库对齐**：原来「音乐」一栏直接数 MediaStore 的全部音频行（铃声、通知音、系统提示音都算在内），比「音乐 → 歌曲」里能看到的曲目多；现在改用曲库的实际条目数，两个地方口径统一。

## v1.5.73

- **去掉重复的音量条**：播放页底部那条常驻音量条删掉了。转盘本来就有一套「进度条 ↔ 音量条」的切换：非拖动状态下转一下转盘，进度条原位换成音量条（两侧是音量图标、时间文字隐藏），继续转就是调音量，停手 2 秒自动换回进度条。两条同时存在属于重复，现在只保留转盘这一套。
- **转盘第一次转动也生效**：以前第一下只是把进度条换成音量条、音量不动，要转第二下才有反应；现在换条的同时就把这一格音量吃掉。
- **硬件音量键跟着走**：音量加减键改的是系统媒体音量，之前靠 `android.media.VOLUME_CHANGED_ACTION` 广播同步，Android 8 上这条隐式广播不可靠，屏幕上的音量条纹丝不动。改成 `VolumeUtil.Watcher`（ContentObserver 盯 Settings.System + 300ms 轮询兜底双保险），按物理键时音量条实时刷新；两套播放页（默认主题 / 3rd 主题）同步处理。

## v1.5.72

- **语言切换真正生效**：此前「设置 → 语言」只算出 configuration 却没应用到 resources，选中文/繁体/英文都毫无变化；现在 Application 与 Activity 在 attachBaseContext 就按偏好套上目标语言，再落一次应用上下文 resources 并重启进程，简中 / 繁中 / 英文全部可用。
- **视频拖动快进**：底部进度条可从任意位置按住左右拖动，拖动时暂停并浮出目标时间气泡，松手才真正 seek；进度条端头加了圆点，明确提示可拖动。
- **视频全屏精简**：去掉全屏下左上角多余的返回键（收回半屏只用右下角按钮）；同时把那条点不动的底部细横线一起收掉，全屏画面干净且不再误导。
- **关于本机改只读信息页**：这页本来没有可进入的下一级，之前多行会同时像被选中、选中又没有任何作用；现在不画选中条、也不跟游标走，只保留「标签 + 数值」，版本行连点 6 次的彩蛋照旧。

## v1.5.71 — 自 v1.5.21 以来的完整差异

> v1.5.22～v1.5.70 为内部迭代版本（仅本机验证，未逐版对外发布）。以下为从公开的 **v1.5.21** 到 **v1.5.71** 的全部变化。
>
> 详细部署与验收见 [DEPLOY.md](./DEPLOY.md)，交给 AI 一键部署见 [AI-DEPLOY.md](./AI-DEPLOY.md)。

### 整机与系统层

- **锁屏**：新增 PodClassic 风格解锁页，拖动滑块解锁；支持自动熄屏。
- **电源键**：长按弹出 PodClassic 风格菜单（锁屏 / 关机 / 重新启动），盖住系统白底菜单；退出时自动收起系统菜单。
- **悬浮退出条**：由「深色圆底 + 白箭头」改为 iOS home indicator 式细横条，**横向滑动**退出，颜色更柔和；视频全屏播放时不显示。
- **返回**：左右屏幕边缘内滑返回。
- **插线**：自动选「传输文件」；新增 MTP「允许访问设备数据」自动点「允许」——换电脑插线即可传歌（adb 调试授权仍需人工点一次）。
- **无障碍**：遍历窗口时排除自身窗口，修掉「点到自己的菜单项导致死循环」；设备管理员激活后自动回桌面。

### 播放与媒体

- 播放页保持常驻音量条、封面 / 歌名 / 艺人 / 专辑 / 进度时间。
- **视频页**：控件默认隐藏，轻触出现、再触隐藏；按键图标缩小；全屏播放不再有悬浮退出条。
- **照片页**：改为 3×2 缩略图墙，点击进全屏查看。

### 游戏（改动最大）

- **全部游戏**：取消「上滑折叠 / 上滑进入音乐控制屏」，只保留侧边滑出，避免误触退出。
- **存档**：退出不清零，重新进入可选择「继续」或「清零」；误触退出不再把进度清空。
- **俄罗斯方块**：棋盘按整数像素格计算，液晶框与格子严格贴边；修掉格子与外框空隙、左右边距不等、顶部框线丢失、控制区压住十字键等问题；利用液晶屏上方空白重排。
- **贪吃蛇**：新增难度分级（‹ › 切换）。
- **飞机大战**：清屏炸弹图标从难辨的圆形符号改为**航空炸弹剪影**；底部虚线改为圆角信息条，图标与数字上下居中。
- **打砖块**：控制带放到挡板下方，按相对位移拖动，手指不再挡住挡板；折叠态去掉多余控制带。
- **扫雷**：整体重做 —— 底部正方形触控板（162dp，约占半个屏宽）+「开 / 旗」两圆键（不再长按插旗）；光标磁吸；鲜红紧凑旗子；三档难度（初级 9×9/10 雷、中级 13×13/30 雷、高级 16×16/48 雷）；难度与剩余旗并入分数栏同一行；数字已满足时按「开」自动扫周围（对应电脑版右键 chord）；结束卡标题区分「全部排除 / 踩雷了」，修掉文案被裁切与卡片透明导致的数字透底。
- **暗黑主题**：游戏界面不再用纯黑底，统一提高明度差；修正部分主题下提示文字看不清的问题。

### 工程与部署

- 版本 **1.5.71 / versionCode 105**。
- 构建：缺 keystore 时自动退回 debug 签名，新机器零配置即可编译安装（代价是跨签名升级需卸载重装）。
- 新增 [DEPLOY.md](./DEPLOY.md)（完整部署手册：环境、构建、装机、无障碍绑定、恢复出厂 25 分钟重建清单、验收表、插线传歌与排障）与 [AI-DEPLOY.md](./AI-DEPLOY.md)（AI 一键部署提示词）。

### 升级方式

```powershell
adb install -r PodClassicXZs_v1.5.71.apk
adb shell settings put secure accessibility_enabled 0
adb shell settings put secure enabled_accessibility_services io.github.xejohv.podclassicxzs/io.github.xejohv.podclassicxzs.gestures.GestureService
adb shell settings put secure accessibility_enabled 1
```

装完**必须重新绑定无障碍**，否则三指手势、电源菜单、插线自动应答都会失效。
